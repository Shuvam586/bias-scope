# BiasScope

A news aggregation and analysis platform for Indian news media. It fetches articles from multiple sources, clusters them into events, and analyzes their stance using ML.

## Scope
- Fetch news from Indian news outlets using RSS feeds
- Parse, clean, and validate articles
- Cluster related articles into events
- Analyze article stance toward relevant topics and entities
- Store articles, events, and analysis results

## Components
- `backend/` - RSS ingestion, article processing, and database operations
- `ml/` - event clustering, NLP analysis, and stance detection
